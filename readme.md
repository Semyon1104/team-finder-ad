# TeamFinder

TeamFinder - веб-приложение для поиска команды под проект. Пользователи регистрируются, создают проекты, указывают нужные навыки, присоединяются к чужим проектам и управляют своим профилем.

## Возможности

- регистрация и вход по email/паролю;
- список проектов с фильтром по навыкам и пагинацией;
- карточка проекта с участниками и списком навыков;
- создание и редактирование проекта владельцем;
- добавление и удаление навыков проекта без перезагрузки страницы;
- завершение проекта владельцем;
- список пользователей и страницы профилей;
- редактирование профиля и смена пароля;
- административная панель Django.

## Стек

- Python 3
- Django
- PostgreSQL
- Pillow
- HTML/CSS/JavaScript
- Docker Compose (для локального запуска БД)

## Быстрый запуск

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте и активируйте виртуальное окружение.
3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте `.env` на основе примера:

   ```bash
   cp .env_example .env
   ```

5. Поднимите PostgreSQL:

   ```bash
   docker compose up -d
   ```

6. Примените миграции:

   ```bash
   python manage.py migrate
   ```

7. (Опционально) заполните демо-данные:

   ```bash
   python manage.py seed_demo_data
   ```

8. Запустите сервер:

   ```bash
   python manage.py runserver
   ```

Приложение будет доступно на [http://localhost:8000](http://localhost:8000).

## Переменные окружения

Минимальный набор в `.env`:

- `DJANGO_SECRET_KEY`
- `DJANGO_DEBUG`
- `DJANGO_ALLOWED_HOSTS` (пример: `localhost,127.0.0.1`)
- `POSTGRES_DB`
- `POSTGRES_USER`
- `POSTGRES_PASSWORD`
- `POSTGRES_HOST`
- `POSTGRES_PORT`
